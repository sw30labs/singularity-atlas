# Accelerando — Markdown edition

*Accelerando*, by Charles Stross. Copyright © Charles Stross, 2005.

This package is a faithful, format-only Markdown conversion of the complete free edition hosted by the author. It was converted on 2026-08-19 without abridging, rewording, or reordering the book's visible text.

## Files

- `Accelerando.md` — the complete book in one Markdown file
- `assets/` — the two cover images and Creative Commons badge used by the Markdown file
- `source/accelerando.html` — the exact author-hosted HTML used for conversion
- `source/accelerando.epub` — the author-hosted EPUB edition, included unchanged
