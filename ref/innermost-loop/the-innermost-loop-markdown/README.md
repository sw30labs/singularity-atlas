# The Innermost Loop — Markdown export

This package contains all **218 editions** of *The Innermost Loop*, from **2025-12-11** through **2026-08-17**.

LinkedIn’s signed-out newsletter page currently exposes only the newest five editions. The complete inventory and article text were therefore retrieved from Dr. Alex Wissner-Gross’s official public mirror, which contains exactly the 218 editions requested. Representative oldest, midpoint, and newest editions were cross-checked against LinkedIn; their authored paragraph text matched exactly after whitespace and typography normalization.

## Files

- `issues/` — one Markdown file per edition, ordered oldest to newest
- `ALL_ISSUES.md` — every edition in one chronological Markdown file
- `INDEX.md` — clickable edition index
- `manifest.json` — structured metadata, counts, hashes, and source links
- `validation_report.json` — completeness and representative cross-check results

Article links and remote image URLs are preserved. The single image-only archive entry, “Davos 2026,” is retained as a media edition. Comments, reactions, recommendation cards, subscription forms, and other interface elements are excluded. Copyright remains with the author and original publishers.
